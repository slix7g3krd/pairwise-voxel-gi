# pairwise-voxel-gi

体素全局光照在角色走进室内时墙角的反弹光突然消失，体素化只按三角形投影，薄墙和门框漏成空洞；clipmap 每级体素尺寸固定，远距离大物体被过度保守填充，整面墙发亮；反弹只算一次，多次散射能量被 albedo 直接吞掉；动态角色没注入体素，走近墙壁时阴影和反弹光对不上；天空遮蔽用固定上半球，室内天花板被当成露天；多相机分屏共享一张 clipmap，左右眼 GI 互相污染；异步体素化在渲染读之前没插 barrier，偶发黑块；体素法线按轴对齐，斜面反弹方向偏 45°；光源移动后只更新直接光，间接光缓存残留旧位置；裁剪距离切换时 clipmap 中心跳变，墙边出现一圈亮带。render/voxel_gi.py 是核心，tests/test_voxel_gi.py 15个红。要修的是：保守体素化带薄几何标记；clipmap 按距离选体素尺寸并做重叠过渡；多次散射能量补偿；动态物体每帧注入；天空遮蔽按法线半球采样；多相机独立 clipmap；异步体素化加 barrier；法线按重心插值；光源移动重建间接缓存；clipmap 中心平滑跟随。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
